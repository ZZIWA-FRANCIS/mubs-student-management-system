# Student Management System (SMS)
**Institution:** Makerere University Business School (MUBS)  
**Course:** Advanced Web Application Development (BUC3131)  
**Academic Year:** 2026/2027 | **Semester:** I  

---

## System Overview
The **Student Management System (SMS)** is a web-based application built with Laravel and MySQL. It provides full role-based access control (RBAC) to manage students, course offerings, and semester course registrations across administrators, lecturers, and students.

---
